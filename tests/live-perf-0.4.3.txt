BetterSpellWheel performance pass (work/bsw-perf), live on SudoBlade 2026-10-14
i9-13950HX / RTX 4080 Laptop, 2560x1600, Windows user sarah, Steam njoy. Worlds: Creative MODTEST
(TradeTesterB) and Standard TRADE_TEST (BSWStdTest), both throwaway test characters.
Method: PerfLog=true. The profiler logs the mod's game-thread time once a second ("busy", ms per second;
os.clock has 1 ms resolution on Windows, so the per-second sums are averaged over 10-20 s), plus engine
object-scan calls and the frame time (GameplayStatics:GetWorldDeltaSeconds). Builds were swapped by hot
reload in the same session: 0.4.2 + profiler, the cooldown branch 98500dd + profiler, and this branch.
"Off" means Enabled=false at runtime, with the loop and profiler still running. The tick loop ran about
46 times a second at 90-140 fps.

Frame rate: on this machine the game is GPU/render bound and the 0.4.2 cost is about 4% of one core,
so FPS differences sit inside run-to-run noise (uncapped, ScreenPercentage 10: off 139/131 fps,
this branch 127/130, 0.4.2 131/135). The FPS drop needs a slower CPU or a bigger object array, where
each FindFirstOf scan per tick costs proportionally more; this machine can't show it.
